پیش‌فرض: اتصال مستقیم. اگر سرور به تلگرام دسترسی نداشته باشد (خطای No route to host / Network is unreachable در تست پایین)، یکی از دو گزینه را فعال کنید. حالت «آدرس پایه سفارشی» فقط موتور web را رد می‌کند؛ برای موتور Telethon باید حالت «پروکسی» را تنظیم کنید.

۴) تست اتصال به تلگرام

این تست از داخل سرور اجرا می‌شود (نه از مرورگر شما) و از همان مسیری استفاده می‌کند که دریافت پیام‌ها استفاده می‌کند؛ اگر سبز شد یعنی سرور از طریق مسیر فعلی به تلگرام دسترسی دارد.

۵) تنظیم هوش مصنوعی و آرشیو

برای تولید خودکار عنوان فارسی، توضیحات، دسته‌بندی و برچسب‌ها، در متغیرهای محیطی برنامه این سه مقدار را تنظیم کنید:

  • AI_API_BASE_URL: آدرس پایه API سازگار با OpenAI، بدون /chat/completions
  • AI_API_KEY: کلید API
  • AI_MODEL: نام مدل

اطلاعات پیام‌ها در SQLite با نام archive.sqlite3 و فایل‌ها در media/ زیر مسیر DATA_DIR ذخیره می‌شوند. برای ماندگاری پس از راه‌اندازی مجدد، دیسک دائمی هاست را فعال کنید. دانلود فایل‌ها از موتور Telethon انجام می‌شود.

اگر API هوش مصنوعی تنظیم نباشد یا خطا بدهد، سیستم با عنوان و دسته‌بندی اولیه ادامه می‌دهد و دریافت تلگرام متوقف نمی‌شود.
