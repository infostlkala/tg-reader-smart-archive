# آرشیو هوشمند کانال تلگرام

وب‌اپلیکیشن Flask برای آرشیو کردن کانال‌های عمومی تلگرام: دریافت پیام‌ها و رسانه‌ها،
تولید خودکار عنوان/دسته‌بندی/برچسب فارسی با هوش مصنوعی، و نمایش آرشیو در یک صفحه عمومی.

## قابلیت‌ها
- حفظ ورود تلگرام و دریافت خودکار پیام‌ها با Telethon
- دانلود رسانه‌ها به مسیر `DATA_DIR/media/<channel>/`
- نمایش عکس‌ها، نام فایل‌ها و لینک دانلود در وب‌سایت
- ذخیره متادیتا در SQLite (`archive.sqlite3`) و نگهداری JSONهای سازگار با نسخه قبلی
- مهاجرت خودکار پیام‌های JSON قبلی به SQLite در شروع برنامه
- تولید عنوان فارسی، توضیحات، دسته‌بندی و برچسب‌ها با API سازگار با OpenAI (اختیاری)
- در صورت نبود یا خطای AI، استفاده از عنوان و دسته‌بندی پایه
- پنل مدیریت: تنظیم کانال‌ها، ورود تلگرام، رله/پروکسی، تست اتصال و عیب‌یابی شبکه

## استقرار روی Railway

1. این ریپو را به GitHub خودتان push کنید.
2. در [railway.app](https://railway.app) پروژه جدید بسازید و **Deploy from GitHub repo** را انتخاب کنید.
3. یک **Volume** به سرویس اضافه کنید (مثلاً mount path: `/data`) — بدون این، داده‌ها با هر Deploy پاک می‌شوند.
4. متغیرها را مطابق `.env.example` تنظیم کنید؛ حداقل این سه:
   - `ADMIN_PASSWORD` — رمز پنل مدیریت
   - `SECRET_KEY` — رشته تصادفی طولانی
   - `DATA_DIR=/data` — همان mount path ولوم
5. از تب **Settings → Networking** دامنه بسازید (Generate Domain).
6. در پنل مدیریت (`/admin`)، موتور `Telethon` را انتخاب کنید، با `API_ID` و `API_HASH` از
   [my.telegram.org](https://my.telegram.org) وارد حساب شوید و کانال‌ها را اضافه کنید.

شروع سرویس از طریق `railway.json` انجام می‌شود:
`gunicorn app:app --bind 0.0.0.0:$PORT --threads 4 --timeout 120`

## اجرای محلی

```bash
python -m venv .venv
.venv\Scripts\activate        # ویندوز
pip install -r requirements.txt
set ADMIN_PASSWORD=xxx        # یا از فایل .env خودتان
python app.py                 # روی http://localhost:8000
```

پیش‌فرض `DATA_DIR` پوشه `data/` کنار پروژه است، پس اجرای محلی بدون تنظیم هم کار می‌کند.

## متغیرهای محیطی

مطابق `.env.example`. خلاصه:
- `ADMIN_PASSWORD`, `SECRET_KEY`, `DATA_DIR` — اجباری
- `API_ID`, `API_HASH`, `TG_SESSION` — برای موتور Telethon (یا ورود از پنل)
- `TG_PROXY` — رله اختیاری اگر سرور به تلگرام دسترسی نداشته باشد
- `AI_API_BASE_URL`, `AI_API_KEY`, `AI_MODEL` — هوش مصنوعی اختیاری (سازگار با OpenAI)
- `WORKER_ENABLED` — `0` برای غیرفعال کردن حلقه دریافت خودکار

## نکات
- حساب باید به کانال دسترسی داشته باشد؛ محتوای خصوصیِ غیرقابل دسترسی دریافت نمی‌شود.
- دریافت کل تاریخچه و رسانه‌های حجیم می‌تواند فضای دیسک و پهنای باند زیادی مصرف کند —
  روی Railway حجم ولوم و پلن خود را در نظر بگیرید.
- فایل‌های دانلودی فقط از طریق مسیر امن `/media/...` ارائه می‌شوند؛ پارامتر `?download=1` دانلود را اجباری می‌کند.
- API هوش مصنوعی فقط برای پیام‌هایی اجرا می‌شود که در دریافت‌های بعدی پردازش می‌شوند. برای استفاده از مدل، سرویس باید با فرمت OpenAI Chat Completions سازگار باشد.
- موتور وب `t.me/s` فقط اطلاعات قابل مشاهده در پیش‌نمایش عمومی را می‌خواند و دانلود واقعی فایل‌ها را انجام نمی‌دهد.
